Architecture applicative

Trois-tiers simple : une SPA React consomme une API REST Spring Boot, qui persiste dans PostgreSQL et sur un stockage de fichiers local. Une tâche planifiée purge les fichiers expirés côté base et disque.

Modèle de données (MCD)

Deux entités suffisent pour le périmètre MVP (US01–US06) : un utilisateur dépose zéro à plusieurs fichiers ; un fichier appartient à exactement un utilisateur (pas d'upload anonyme dans le MVP). 

erDiagram
    UTILISATEUR ||--o{ FICHIER : depose
    UTILISATEUR {
        uuid id_utilisateur PK
        string email UK
        string mot_de_passe_hash
        timestamp date_creation
    }
    FICHIER {
        uuid id_fichier PK
        uuid id_utilisateur FK
        string nom_original
        string nom_stocke
        string type_mime
        bigint taille_octets
        string mot_de_passe_hash "nullable"
        timestamp date_expiration
        timestamp date_creation
    }

Lecture Merise — UTILISATEUR (1,1) ──< DEPOSE >── (0,n) FICHIER. Le statut « Actif / Expiré » affiché dans les maquettes n'est pas une colonne : il se déduit de date_expiration > now() au moment de la requête.
